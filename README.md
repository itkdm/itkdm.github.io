# mywebsite

哈喽！这里是布吉岛的技术站点。

这里主要分享布吉岛的经验，可能包括一些开发踩坑经历，可能有一些系列教程，也会有一些简单的小工具，也会持续更新我在 Vibe Coding 与 Coding Agent 深度使用中的实战方法。除了代码与 AI 科技内容，你也能看到我的人生思考和一些奇思妙想。

## 读者能获得什么

- 快速找到你感兴趣的博客内容，获取真实问题的分析过程
- 在文档教程里系统学习一个主题，不只知道“怎么做”，也知道“为什么”
- 直接使用或下载常用软件与工具，减少重复搭建成本
- 看到 AI 与工程实践结合的具体案例，获得可迁移的方法

## 站点内容

- 博客：服务端开发、AI 编程、技术实践复盘，以及个人思考
- 文档：主题化教程与知识整理，适合连续阅读和体系化学习
- 项目：真实项目中的设计取舍、实现路径与经验沉淀
- 工具：可直接使用的在线工具，解决具体场景问题
- 下载：常用软件与资源合集，方便快速上手

## 适合谁看

- 关注服务端开发，希望提升工程能力的开发者
- 对 Vibe Coding 和 Coding Agent 有兴趣，想看真实使用经验的人
- 喜欢技术之外的人生思考和创意表达的读者

## 怎么使用这个网站

- 想找灵感：先看博客，快速找到你关心的话题
- 想系统学：直接进入文档教程，按主题深入
- 想拿来即用：查看工具和下载栏目，优先解决手头问题
- 想精确定位：使用站内搜索输入关键词直达内容
